# 🛡️ SentinelAI

### Autonomous AI Security Research Agent

SentinelAI is an autonomous AI-powered research agent designed to discover, evaluate, remember, and publish high-quality research insights based on a user-selected domain.

The system combines a web-based frontend, Node.js/Express backend, MongoDB, and Gemini AI to create an autonomous research pipeline.

---

## 🚀 Overview

SentinelAI allows users to create an AI research agent by providing:

- Agent name
- Research domain
- Custom domain

After an agent is created, SentinelAI can autonomously:

1. 🔎 Discover research topics
2. 🧠 Evaluate topics using AI
3. 📊 Score topics based on editorial criteria
4. ✅ Publish valuable topics
5. ❌ Reject low-quality topics
6. 📝 Generate research posts
7. 💾 Store research memory
8. 📈 Track autonomous activities
9. 🔄 Run autonomous research cycles
